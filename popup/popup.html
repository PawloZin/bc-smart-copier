BC Smart Copier
v1.3.0
Extension is active
How to use
Copy cell value

Left-click any cell or field to copy its plain text value.
Example: 10000 or [No.]

Copy action path

Click an action button to copy its full BC navigation path.
Direct: open page [Sales Order] and go to [Home] tab and click {Post}
Submenu: open page [Sales Orders] and go to [Related] tab -> [Documents] and click {Prepayment Invoices}

Keyboard shortcuts

Both actions cannot use the same shortcut.

For Microsoft Dynamics 365 Business Central
