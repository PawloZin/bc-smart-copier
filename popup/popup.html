How to use
Copy cell value

Left-click any cell or field to copy its plain text value.
Example: 10000 or [No.]

Copy action path

Click an action button to copy its full BC navigation path.
Direct: open page [Sales Order] and go to [Home] tab and click {Post}
Submenu: open page [Sales Orders] and go to [Related] tab -> [Documents] and click {Prepayment Invoices}

Copy whole table

Hold the keys and point at any table — it gets a green outline. Click it to copy all visible rows as tab-separated text, ready to paste into Excel.

Keyboard shortcuts

Each action needs a different shortcut.

Error reports

When Business Central shows an error, buttons copy it for an AI agent or for Jira — with the environment, page, error details and the current record.
